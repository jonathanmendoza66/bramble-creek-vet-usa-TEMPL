# Bramble Creek Veterinary Hospital — Color & Font Guide

---

## Color Palette Overview

The site uses a nature-inspired, earthy color palette that evokes trust, warmth, and professionalism. Think: a walk through a lush Ohio forest on a golden afternoon. No purples, no neons — just calm, grounded tones that feel like a caring veterinary practice should.

---

## Color Usage Rules (Quick Reference)

1. **Primary green** = trust, brand identity, navigation, main buttons
2. **Warm gold** = calls to action, urgency, "book now" buttons, star ratings
3. **Teal accent** = secondary features, variety, fear-free branding
4. **Cream background** = overall warmth, avoids sterile white
5. **Sage** = community, nature, earthiness
6. **Red** = emergencies only (after-hours info, "closed" status)
7. **Body text is always dark gray** (#1f2937), never pure black

## Fonts

### Headings: Playfair Display

| Property | Value |
|----------|-------|
| Font name | Playfair Display |
| Source | Google Fonts |
| Weights used | 400 (regular), 500 (medium), 600 (semibold), 700 (bold) |
| Used for | All headings (h1-h6), practice name, decorative text |
| Style | Serif (traditional, elegant) |

**In plain terms:** This is an elegant serif font — the kind with little "feet" on the letters. It looks like something you'd see in a quality magazine or a high-end brand. It gives the practice a sense of history, trustworthiness, and sophistication without being stuffy. Think: classic, refined, established.

**Line height for headings:** 1.2 (120%) — tighter spacing to look bold and impactful.

---

### Body Text: Inter

| Property | Value |
|----------|-------|
| Font name | Inter |
| Source | Google Fonts |
| Weights used | 300 (light), 400 (regular), 500 (medium), 600 (semibold), 700 (bold) |
| Used for | Paragraphs, buttons, labels, navigation, form fields, everything else |
| Style | Sans-serif (clean, modern) |

**In plain terms:** This is a clean, modern font without the decorative "feet." It's one of the most readable fonts on the web — designed specifically for screens. It feels professional, approachable, and easy to read at any size. It's the workhorse font that all the regular text uses.

**Line height for body:** 1.6 (160%) — generous spacing for comfortable reading.

---

### Font Pairing Logic

The combination of Playfair Display (serif headings) + Inter (sans-serif body) is a classic pairing that creates:

- **Visual hierarchy** — headings immediately stand out from body text due to the style contrast
- **Professionalism** — serif headings add gravitas and tradition
- **Readability** — sans-serif body text is optimized for long-form reading on screens
- **Balance** — elegant but not fussy, modern but not cold

### Font Weight Usage

| Weight | Name | When to Use |
|--------|------|-------------|
| 300 | Light | Large decorative text only |
| 400 | Regular | Body paragraphs, descriptions |
| 500 | Medium | Navigation links, button text, labels |
| 600 | Semibold | Headings, card titles, emphasis |
| 700 | Bold | Page titles (h1), hero text, strong CTAs |

**Rule of thumb:** Never use more than 3 different weights on a single page/section to maintain visual consistency.
